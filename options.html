Repo Picker

Type gh in the address bar, press space, then start typing a repository name.

Every repository you can read under these accounts gets indexed. Organizations and users both work, and so does a full URL, so https://github.com/acme and acme are the same thing.

Create a fine-grained token Classic token

Fine-grained

Reach for this one first. Set the resource owner to your organization and grant a single permission, Repository permissions → Metadata → Read-only. That is precisely what listing repositories needs, and a token holding it can change nothing.

Two things get in the way. Plenty of organizations require an admin to approve every fine-grained token, so you may be waiting. And GitHub ignores prefill parameters on that page, so you fill the form in by hand.

Classic

Reach for this when the other one is blocked: your org has not enabled fine-grained tokens, approval would take days, or you want this working in the next minute. The button fills the form in for you, so it is two clicks.

The price is the repo scope, which also grants write access to every repository you can reach. For something that only reads names, that is far too much, and GitHub offers nothing narrower that can see private repositories. The scopes listed underneath it are locked on rather than optional.

Where the token ends up

In this browser profile's extension storage, as plain text. Firefox has nowhere to put an extension's secret that other software on the machine cannot read, so anything with access to your profile directory can read this one. It is sent only to api.github.com, and never anywhere else.

Two things help. The classic button asks GitHub for a token that expires in six months, and Repo Picker tells you when that date is near. And the list of repositories keeps working without the token, so you can index once, click Forget token, and paste a new one in when you want a fresh index.
